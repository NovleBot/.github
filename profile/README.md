## Nuestra forma de trabajar

```text
Descubrir → Diseñar → Construir → Lanzar
```

**01 — Descubrir**
Entendemos el negocio, sus necesidades y el problema que queremos resolver.

**02 — Diseñar**
Definimos la experiencia, arquitectura y estructura de la solución antes de desarrollar.

**03 — Construir**
Desarrollamos, probamos y mejoramos la solución de forma iterativa.

**04 — Lanzar**
Publicamos el proyecto, realizamos las pruebas finales y dejamos la solución lista para operar.
